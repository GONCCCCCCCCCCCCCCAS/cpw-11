Sessão de aprendizagem

Nesta sessão vamos aprender a organizar páginas web utilizando HTML e CSS. Vamos trabalhar na estrutura, apresentação e distribuição dos conteúdos.

Material necessário

  • Computador
  • Visual Studio Code
  • Ligação à Internet
  • Navegador web

09:00 — Receção

Receção dos participantes e apresentação da sessão.

10:00 — Atividade prática

Desenvolvimento de uma página utilizando HTML e CSS.

11:30 — Conclusão

Apresentação dos trabalhos e revisão dos conteúdos.
